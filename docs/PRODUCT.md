# 产品设计：随行组件
状态：独立卡片原型已实现，正式框架仍按目标设计推进；使用见 [DEMO](DEMO.md)。

## 使用方式

用户打开系统面板时，在旁边查看待办、天气、系统状态和常用入口；看完收起。快速设置与通知中心分别可选，快捷键和托盘提供独立入口。组件不需长期占用壁纸或改变桌面图标。

单条消息的通知横幅不触发组件；后台观察到 Shell 窗口不足以自动显示，必须确认通知中心或快速设置身份。面板已打开时收到消息不改变当前跟随对象。

主控制程序使用 C++ / WinUI 3，左侧集中设置，右侧直接管理组件启停、设置、重启和顺序。当前每个组件一个独立进程和数据目录，支持零代码组件和用户自编程 DLL MOD，已通过通用接口接入旧原生 SDK。蓝牙电量作为独立示例提供，不属于内置业务。多实例与更多能力仍为后续设计。

## 视觉与布局

- 每张卡片为独立窗口，宽 320 DIP、外间距和卡片间距 8 DIP、内边距 16 DIP、圆角 8 DIP；外观贴近 Windows 自带面板。
- 默认从系统面板旁右下角向上排列，再向左扩展；系统面板以外的工作区可用于卡片。关闭自动排列后可拖动标题，自由位置按工作区比例保存。
- 不提供时钟、日历和专注计时，避免重复 Windows 功能。
- 根据系统面板两侧可用空间选择位置，默认底部对齐，靠近日历底边和任务栏，并限制在工作区域；通知上方空白不影响垂直位置。空间不足时隐藏自动跟随，保留手动入口。
- 统一排版，长内容滚动；每显示器 DPI 控制像素转换，卡片尺寸使用 DIP，自由位置按工作区比例保存。
- 支持系统/明/暗主题。临时面板使用系统 Acrylic 半透明背景及其默认明暗配方，有不透明背景回退；原型已实现系统主题跟随和手动覆盖。
- 每张卡片的背景和内容一起进出，全部卡片共用动画状态、时钟、曲线与帧调度器，重排也使用统一曲线；系统关闭动画时直接开关。真实通知中心动画同步程度需按 Windows 构建实测。
- 第三方提供内容、动作、图标与尺寸建议，不能擅自改变面板的置顶或焦点。

原“一个桌面图标为单位”的尺寸需求归入旧桌面模式。新布局仍可用 3×2、1×2 跨度，但单位是面板自身的布局格，不依赖 Explorer 网格。正式格宽与列数随面板宽度定义；demo 已实现独立卡片自动排列和自由拖动，正式 SDK 网格编辑尚未接入。

## 交互

勾选、播放/暂停、按钮与滑块属于轻交互，尝试保持系统面板激活。文字输入、搜索与复杂设置另开可正常激活的编辑窗口，此时允许系统面板自然收起。

若不激活点击仍导致系统面板关闭，就采用“自动跟随查看 + 手动面板完整交互”。不得通过循环重开通知中心掩盖失败。

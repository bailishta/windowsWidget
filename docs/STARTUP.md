# 托盘、隐藏与开机启动

单击托盘图标打开主控制中心。托盘右键保留“打开控制中心”和“退出”，以下功能直接放在主界面：

| 菜单 | 行为 |
| --- | --- |
| 打开控制中心 | 显示主窗口，也可直接双击程序打开已有窗口 |
| 隐藏托盘图标 | 开关立即生效并保存在 manager.json；程序继续运行，双击主程序可重新打开设置，关闭开关恢复图标 |
| 主窗口右上角关闭按钮（×） | 隐藏控制中心，保留组件进程及通知中心跟随 |
| 预览 / 收起组件 | 独立控制手动预览，不等同于隐藏主窗口 |
| 开机自启动 | 勾选后在当前用户登录 Windows 时运行；取消后删除本程序的启动项 |
| 开机静默启动 | 勾选后登录时只驻留托盘；取消后登录时打开控制中心 |
| 退出 | 结束主程序并关闭所有组件进程 |

开机自启动默认关闭，静默启动默认开启。静默选项可以先设置，但只有启用自启动才会在登录时生效。普通双击程序始终打开控制中心；重复的后台启动不会把已隐藏的主窗口重新打开。隐藏主窗口是本次运行的操作，不会自动改动静默选项、组件启停或预览状态。

静默运行时，组件仍随通知中心或快速设置出现和收起，不会因启动而自动进入预览模式。Windows 可以延后执行登录启动项，实际时机由系统决定。

隐藏托盘图标默认关闭。选择在重启程序后保留；资源管理器重启时也遵守该选项。隐藏图标不改变组件的运行、显示或开机启动设置。

## 设置保存

静默选项保存在 `%LOCALAPPDATA%\WindowsWidget\CompanionDemo\startup.json`，使用 `--data-dir` 时保存在指定目录。

```json
{"schema": 1, "silent": true}
```

采用临时文件写入后替换。文件损坏或版本不兼容时保留原文件，使用静默默认值，并在控制中心提示；不会为保存新设置而覆盖损坏文件。

自启动写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `WindowsWidget.Companion`。只在用户切换主界面自启动开关时修改，不需要管理员权限，不改动其他程序的值。

启动命令保存可执行文件完整路径和 `--autostart`；显式指定的数据目录与英语选项也会保留。登录时读取静默设置；`--background` 则始终隐藏主窗口。程序目录移动后，取消再勾选自启动可登记新路径。Windows 设置或任务管理器中禁用启动应用，也会影响是否运行。

命令长度遵守微软 [Run 注册表项文档](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys) 的 260 字符限制。路径过长或保存失败时显示错误，不虚报启用成功。

## 验收

自动检查使用独立数据目录和唯一、易失的注册表测试键，验证命令引用、启用/更新/禁用、无关值保留、静默设置恢复及损坏保护。隐藏窗口测试验证主窗口隐藏或关闭后，组件进程和跟随会话保持。测试不启用用户实际的 Windows 启动项。

真实托盘点击、退出再打开后的勾选状态、注销或重启后的静默效果由用户操作，见 [手动测试](MANUAL_TESTS.md)。

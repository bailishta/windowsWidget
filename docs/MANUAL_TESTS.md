# 手动测试
鼠标与系统面板操作由用户完成，不做自动输入。

## 浅色组件背景闪烁

当前 ShadowlessCards 版本已去除组件之间的 DWM 投影，使用组件自己的持久圆角。检查顶部无暗带、四角完整，大小或动画变化后没有残留裁剪；控制中心等普通窗口仍使用系统装饰。

1. 在控制中心选择浅色，打开 Win+N / Win+A，等待动画结束，观察天气、常用入口、系统状态卡片顶部至少 30 秒；标题区及上半部分背景应保持稳定，CPU 曲线仍每秒更新。
2. 重复打开/关闭及切换深浅色，确认没有残留裁剪、黑块或位置跳动；关闭系统动画后重复。
3. 以 150% 缩放显示，再单独重启一个组件：窗口尺寸和位置应恢复正确；自动排列和自由拖动后背景仍保持稳定。

## 待办筛选与编辑窗口

1. 主界面应没有“创建自己的组件”入口，组件库与文件导入保持可用。
2. 打开“管理待办”，标题栏和内容标题都使用待办图标，深浅主题与正文一致。
3. 完成一个待办，点击“隐藏已完成”：完成项隐藏，未完成项仍显示；点击“显示已完成”可恢复，关闭再启动后记住选择。
4. 隐藏已完成时再勾选一个待办，该项立即隐藏；全部完成时显示提示。编辑窗口中仍可管理所有任务。
5. 输入未提交的草稿，再删除一项待办或切换筛选，窗口不重新加载、草稿不丢失。

## 托盘隐藏与开机启动

1. 退出旧版本后运行新版。确认主界面没有“隐藏主窗口”按钮；点击主窗口右上角关闭按钮：主窗口消失，组件仍随 Win+N / Win+A 正常出现和收起；单击托盘或普通双击程序可重新打开主窗口。
2. 点主窗口关闭按钮，确认只隐藏且托盘仍在；组件的启停、数据和运行状态保持。
3. 勾选“开机自启动”和“开机静默启动”，正常退出再手动打开：两个勾选状态应保留，手动启动仍显示主窗口。
4. 保持两个选项勾选，注销或重启并登录：主窗口不弹出，只驻留托盘，打开通知中心可正常显示组件。
5. 取消“开机静默启动”但保留自启动，注销或重启：登录后控制中心可见。
6. 取消“开机自启动”，注销或重启：程序不自动运行；其他程序的启动项不受影响。移动新版目录后取消再启用，检查登记新路径。
7. 英语模式检查主界面启动开关、托盘菜单和隐藏功能。自定义数据目录及带空格、中文的程序路径也需验证。

自动检查不操作真实 Windows 启动项，不代替以上鼠标和登录验收。

记录系统版本/构建、分辨率/缩放、主题、语言、启动参数和面板类型。未测试版本标注未验证。

## 点击与关闭

1. 启动独立 demo，自行 Win+N，确认系统面板与组件并排可见。
2. 点击待办，确认勾选与通知中心是否保留。
3. 切换主题，观察是否收起。
4. 重复 Win+A，分别测试严格筛选；严格模式无显示记“类型未识别”。
5. 找日志 pointer_press 和同 action_id 的 click_probe，比较 foreground_same、shell_observed、shell_open、elapsed_ms。
6. 点击正常应用/桌面，检查系统面板与组件自然收起。
7. 点组件“收起”，当前系统面板仍开着时不重弹；关闭再打开后恢复。
8. 手动预览应独立存在，收起/退出正常。

修正版先 Ctrl+Alt+Q 或托盘退出旧 Demo，再打开 PanelFollow 下的 exe。先不启用预览，直接 Win+N 测自动出现；然后启用左下侧预览再 Win+N，确认自动移动到旁边。切换任一筛选后重复。状态应为“跟随通知中心”或“跟随快速设置”，不能仍停留在预览提示。日志 startup 的 build 应为 panel-follow-6、follow_policy 为 confirmed_panels_only、alignment 为 bottom。不要运行有崩溃的早期 FluentFollow。

## 本次重点：消息横幅排除

1. 默认自动模式、通知中心关闭时等待实际消息通知：横幅正常出现，组件不出现、不拦截回复或关闭按钮；较长文本、带回复框或多个横幅也重复。
2. 横幅仍显示时打开 Win+N：组件随通知中心出现并保持正常位置。关闭通知中心但横幅还在时，组件收起。
3. 通知中心已打开时收到新消息：组件继续跟随通知中心，不能跳到横幅旁边或异常收起。
4. 默认模式及通知中心/快速设置筛选分别回归 Win+N / Win+A。手动预览开启时，消息横幅不移动预览；用户自行收起或退出。
5. 日志的未知横幅应为 follow_eligible=false / panel_identity_unconfirmed，不应有以它为源的 panel_shown。观察日志不能替代真实视觉验收。

## 本次重点：透明背景与整体动画

1. 没有通知时打开 Win+N：组件在日历旁边，底边接近日历底边和任务栏，不能沿通知窗口上方的空白区域顶端定位。
2. 有通知、折叠/展开日历时重复：组件底部位置保持靠下，并排且不出工作区。较小屏幕允许缩短面板高度。
3. 连续快速打开/关闭：背景和内容一起平移，不反复重播入场，不留下静止底板；中途关闭/重开从当前进度反向，不发生尺寸抖动。退场时不接收卡片点击；在浏览器全屏视频中回归同样操作。
4. 关闭系统“动画效果”后重复：组件直接显示/隐藏；开启后完整入场 250ms、退场 167ms，观察是否明显落后于通知中心、是否掉帧。上述时长是 Fluent 基准，真实同步不能由隐藏测试替代。
5. 日志 panel_shown/panel_repositioned 的 bottom 应贴近日历/工作区底边，位置未变时不应持续有 panel_repositioned。observed_to_show_ms 仅用于检查程序内调度，不能代替视觉帧率或真正的 Shell 起始时间。

6. 明暗主题下将普通窗口放在组件后面，比较它与通知中心的模糊、透明度、卡片边框；关闭系统“透明效果”后检查可读的不透明回退，再恢复。高对比度也需实测。
7. 多次切换组件主题，检查不会崩溃，任务勾选不丢失；托盘恢复“跟随 Windows 主题”，检查系统明暗变化。不要把仅切换应用主题视作系统主题变化。

自动开关、按钮保留通知中心、浏览器全屏视频及 BottomFollow 底部对齐已由用户确认；上述新版行为由用户复测，自动检查不代替鼠标与视觉验收。

PointerPressed 可能发生在激活变化后，采样有调度延迟。结合 mouse_activate_blocked / unexpected_panel_activation 和实际截图判断。foreground_same 不等于 Shell 一定保留，shell_open 也不证明无遮挡。托盘/日志目录操作会改变前台，不纳入轻交互结果。

## WidgetCards 新版检查

- WidgetFollow 回归：普通启动时组件隐藏；重复打开/关闭通知中心和快速设置，组件都随之显示/隐藏。
- 先用快捷键预览，再打开系统面板：预览被接管，关闭系统面板后组件不能重新回到右下角常驻。
- 在自动跟随中切换排列、启停或重置位置，关闭系统面板后仍应收起；文字编辑结束后恢复自动跟随。

- 打开通知中心：卡片在旁边保留 8 DIP 间距，靠右下角向上和向左扩展，全部同时进出。
- 展开和收起系统日历：卡片跟随实际保留区，移动时不覆盖系统面板。
- 快速开关：全部卡片从共同进度反向，不单独延迟；关闭系统动画后立即完成。
- 关闭自动排列，拖动每张卡片标题；不可拖入系统保留区或任务栏，可以与自己的卡片自由叠放。
- 重启、切换 DPI 或工作区大小，自由位置恢复且不出屏；恢复自动排列后回到右下角顺序。
- 启停每种组件：自动布局补位，关闭天气后其他卡片仍可出现；至少保留一张。
- 添加、勾选待办，重启确认保存；在编辑窗口中删除条目并确认保存。
- 天气切换城市/自定义 API、设置更新间隔、等待自动更新和失败后的下周期重试；旧请求结果不能覆盖新城市或新接口。API 可用请求头认证，支持嵌套/数组字段路径及 °F、m/s、mph 转换。温度缺失时提示失败，其他字段缺失时省略；认证值不能明文写入配置。主界面和天气卡片没有天气更新按钮。
- 系统状态以紧凑细网格图显示真实 CPU / 内存使用率，每秒采样，最多保留 60 点。三个常用入口可分别设置名称、目标和启动参数，保存后立即更新卡片，重启后恢复；目标为空的槽位保持存在但禁用。
- 浅色、深色、高对比度和透明效果关闭时，文字与边框清晰；内容和按钮不裁切。
- 普通模式轻交互、全屏和多屏继续实测；`--inspect` 会激活卡片，不能用于不激活验收。


## 控制中心与独立组件

- 主程序启动打开控制中心；关闭窗口继续驻留，托盘单击或再次运行重新打开。
- 主窗口直接启停、设置、重启、移动顺序、全开/全关；管理不残留常驻预览。
- 天气城市/API、三个常用入口和待办编辑从主控制中心直接打开，标题栏统一主题，修改写入自己的目录。
- 从组件库安装便签、文字、蓝牙电量；导入自己的 checklist / links 包；每项有不同 PID。“我的清单”和“开发入口”不再出现在组件库，升级保留对应业务数据和包备份。
- 待办在原卡片内添加、回车提交、改名、勾选、删除；编辑其他行时删除前面的行，草稿与编辑目标保持正确。完成项筛选、主题切换不清空草稿。输入区、底部按钮和滚动条没有重叠。
- 便签在原卡片内输入中文及换行，停止输入后自动保存；完成编辑、切换到主程序、退出和重启后恢复，整个过程没有独立编辑窗口。
- 从通知中心进入待办、便签编辑，组件位置不因系统面板关闭而跳动；完成或切换到其他应用后恢复自动跟随。非编辑状态的勾选和按钮仍不抢焦点。移除再导入相同 ID 恢复数据。
- 目录中新建或编辑 widget.json，重新扫描发现并重载。重复 ID、坏 JSON、错误版本和非法 URL 显示错误而不覆盖已有组件。
- 单个子进程异常退出，其他继续工作；单独重启恢复，不无限重启。
- 自动排序与自由拖动均避开系统面板，150% DPI 和负坐标屏幕正确；新增/启停/排序仍共用动画。
- 真实通知中心和快速设置多次打开/关闭，所有启用的组件同步显隐。检查默认模式而非 --inspect。

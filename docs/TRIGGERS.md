# 自定义触发

每条规则定义启用、来源、目标面板、显示器策略、隐藏方式与轻交互模式。通知中心、快速设置、快捷键、托盘是不同来源。Win+N 与 Win+A 不合并。

以下是拟议配置，当前主程序和 demo 没有实现此格式：

```json
{
  "formatVersion": 2,
  "triggers": [
    {"id":"notifications","enabled":true,"source":"shell.notifications","panel":"daily","monitor":"source"},
    {"id":"preview","enabled":true,"source":"hotkey","keys":"Ctrl+Alt+W","panel":"daily","monitor":"cursor"}
  ]
}
```

框架无需截获或重发系统快捷键；用户配置的触控板手势也可以唤出系统面板。demo 只注册 Ctrl+Alt+W / Ctrl+Alt+Q，冲突记日志并保留托盘。

## 状态

| 状态 | 行为 |
| --- | --- |
| Hidden | 隐藏，保留实例 |
| Pending | 等待候选状态稳定 |
| VisibleFollow | 跟随已确认的系统面板 |
| VisibleManual | 用户主动打开，独立存在 |
| Unknown | 正式产品隐藏，提供手动入口 |
| Suspended | 用户暂停或主动收起本次跟随 |

已识别的系统面板优先接管手动预览的位置，预览不阻止跟随；系统面板关闭后，明确开启的手动预览回到左侧。切换托盘筛选立即退出预览并回到自动跟随。点“收起”后，本次系统面板关闭之前不重新弹出；关闭后再打开才恢复。多个候选优先前台，其次保持已跟随对象，不能只取枚举到的第一个。

已发现的原生窗口开关直接触发显示，不增加 150–200ms 的显示等待。原生采样目标周期 32ms、UI 读取定时器 16ms；实际响应受系统调度影响。详细识别独立运行，已识别面板打开 200ms 后读取布局，每窗口最多一次/秒，避免沿着 Shell 的每个动画帧重排。

呈现层独立维护 Hidden / Entering / Visible / Exiting，完整进出时长分别 250ms / 167ms；重复状态不重播，反向保留当前进度。观察到 Shell 失去原有前台激活链时尝试提前退场，防止窗口直到最终 cloak 才开始关闭；该推断按构建验证，不是 Shell 官方状态契约。普通关闭播放退场，过期快照/无空间立即隐藏；用户禁用系统动画时直接开关。尚未验证与 Shell 动画的真实时间差或帧率。

## 观察与降级

观察器的原生工作线程组合 EnumWindows、Shell 线程窗口枚举、FindWindowEx 与前台根窗口，每 500ms 更新发现，快速采样已发现窗口并重新校验进程/类身份。独立 MTA 线程用只读 UI Automation 补充通知中心、日历和快速设置身份及内容范围；结果缓存不跨 HWND 进程身份或已变化的原生矩形使用。UIA 查询设连接/事务超时，不能阻塞原生采样或 WinUI；原生快照过期时隐藏。标题/辅助功能名称只用于本机类型提示，不写日志；身份仍可能随版本和语言改变。

定位优先使用有效原生矩形；透明全屏宿主改用实际内容范围。通知与日历分属多个窗口时合并相邻范围，再计算左/右侧间距。默认底部对齐并限制在工作区域，靠近日历和任务栏，忽略通知上方空白。无系统面板时预览在左下侧，不占通知中心所在的右侧列。

默认跟随已确认的通知中心和快速设置，类型筛选可限定其中一种。所有自动模式排除未确认身份的窗口，通用 CoreWindow / ControlCenterWindow 类本身不作为身份依据；尺寸、位置、是否前台也不能单独确认面板。消息横幅和面板可能共用窗口类，仍可收集到观察清单，但不会触发、抢走已跟随的面板或参与合并布局。面板关闭后只剩消息横幅时，组件收起；显式手动预览按自己的生命周期保留。

查询失败、空间不足或识别失败不主动打开系统面板，保留手动预览。Shell 重启重新发现，不复用销毁窗口。

显示使用 WS_EX_NOACTIVATE / WS_EX_TOOLWINDOW、WM_MOUSEACTIVATE 返回 MA_NOACTIVATE、HWND_TOPMOST / SWP_NOACTIVATE；隐藏移除置顶。这不能保证外部点击不导致 Shell 收起，也不能越过特殊层级。依据见 [RESEARCH](RESEARCH.md)。

# 手动验收清单

请从分发目录启动 `WidgetManager.exe`。首次运行在 `%LOCALAPPDATA%\WindowsWidget` 创建配置并添加内置时钟到插件列表；选择时钟，点击“添加到桌面”。

| 操作 | 预期 |
| --- | --- |
| 添加两个时钟 | 两个实例独立显示，管理器中都是“运行中”，落在不同空闲网格位置，避开已有图标 |
| 拖动顶部、拖动底部/右侧边缘 | 可以移动和缩放；锁定布局后不再响应这些操作 |
| 将时钟拖到图标或另一组件附近后松开 | 吸附到最近空闲网格；不会移动原来的图标，不会覆盖另一组件 |
| 选择 3×2、1×2、1×1 并应用大小 | 外框分别占对应格数；1×1 时钟仍有时间，紧凑布局隐藏日期 |
| 拖动右侧或底部边缘缩放 | 按整数格变化，管理器更新格数；锁定后尺寸控件不可编辑 |
| 修改桌面图标大小，再等待片刻 | 格数保留，组件像素尺寸跟随当前格距变化并避让；无空位时显示原因 |
| 切换 English / 中文，再退出重启 | 管理器、托盘、拖动栏和时钟日期切换到所选语言，重启保留 |
| 切换浅色、深色、跟随系统 | 管理器及两个时钟同步变化，深色文字清晰可读 |
| 右键一个时钟切换 12/24 小时制 | 只改变这个实例；重新启动后仍保留 |
| 打开普通窗口覆盖时钟，再按 Win+D | 时钟处于桌面层，不应变成置顶窗口或消失后无法恢复 |
| 点击和拖动小组件区域以外的桌面图标 | 图标正常操作，桌面菜单正常打开 |
| 在管理器停用、启用、重试、移除一个实例 | 只影响所选实例；另一个继续运行 |
| 关闭管理器窗口 | 小组件仍运行，可以从系统托盘重新打开 |
| 托盘退出，再次启动 | 所有组件随退出消失；重启恢复位置、尺寸、设置和主题 |
| 点击底部“打开日志”，并切换中英文 | 打开当前数据目录下的 logs 文件夹，按钮分别显示“打开日志 / Open logs” |
| 添加、停用、启用实例，再查看 manager.log | 存在对应 instance ID 的操作记录、握手与就绪耗时；失败时有错误原因 |

如有多显示器，再测试跨屏拖动、混合缩放和断开副屏。Explorer 重启后的恢复属于进一步兼容性测试，可在方便时再做。

遇到问题时，记录“操作步骤、预期、实际表现”，附截图和 `%LOCALAPPDATA%\WindowsWidget\logs` 中对应日志。若测试使用 `--data-dir`，日志在指定目录下。不要删除配置文件，以便定位恢复问题。

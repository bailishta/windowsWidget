# 变更

## 2026-10-03 · v0.1.0 EXE 安装版

新增 Inno Setup 安装器和 build-installer.ps1。默认按当前用户安装到 LocalAppData/Programs/WindowsWidget，支持开始菜单及可选桌面快捷方式，随包携带 WinUI 与 VC++ 运行库。安装及卸载调用主程序正常退出流程，升级与卸载保留配置、待办和导入组件；卸载只清理指向本安装目录的自启动登记。

本次源码完成 Release/x64 构建，中英文各 319 项自测、各 37 项启动设置检查及 75 项独立进程检查通过。安装器在中文带空格的隔离路径完成安装、运行中升级、卸载与数据保留的 84 项检查。初始安装版版本号为 0.1.0，当前安装包未签名。

## 2026-10-03 · 蓝牙电量组件移除设置入口

蓝牙设备电量组件声明 has_settings=false，主控制中心不再显示其“组件设置”按钮；该组件只负责展示已连接设备和真实电量，后台检测继续自动运行。组件清单增加可选布尔字段 has_settings，默认 true，纯展示组件可通过清单关闭设置入口，管理器同时阻止发送设置命令。

## 2026-10-03 · 移除主界面的隐藏主窗口按钮

删除控制中心“管理与显示”中的“隐藏主窗口”按钮。点击主窗口右上角关闭按钮仍隐藏控制中心并保留组件运行；现有托盘和启动选项保持。

## 2026-10-03 · 移除重复示例与卡片内编辑

移除“我的清单”和“开发入口”两个默认示例；升级时将已安装的同 ID 包移到 removed-plugins，独立业务数据保留。组件库、缓存输出和新目录包不再提供这两个示例，第三方 checklist / links 类型仍可导入。

待办的新增、改名和删除改为原卡片内完成，支持回车提交、完成项隐藏，删除其他条目保留草稿和正确的编辑目标。便签直接编辑原输入控件，停止输入 500 毫秒后自动保存，完成或离开组件时立即保存。编辑期间仅对应卡片接收键盘输入，管理器保留当前位置与系统区域避让；退出编辑后恢复非激活行为和自动跟随，不创建独立待办或便签编辑窗口。

## 2026-10-03 · 隐藏托盘图标开关

主界面的“启动与托盘”增加“隐藏托盘图标”，即时隐藏或恢复系统托盘图标，并保存到 manager.json。主程序及组件继续运行，双击主程序仍可打开设置。登录启动和资源管理器重启遵守该选择。移除误恢复的托盘“隐藏主窗口”菜单项，主界面的隐藏主窗口按钮保留。


## 2026-10-03 · 主窗口滚动条与托盘隐藏入口

主窗口左右两个独立滚动区域在内容右侧各预留 20 DIP 空间，避免 WinUI 展开的滚动条遮挡按钮和卡片。托盘右键恢复“隐藏主窗口”，主界面的隐藏入口保留；开机自启动和静默启动仍直接在主界面设置。


## 2026-10-03 · 主界面启动设置与待办筛选

移除“创建自己的组件”按钮和创建窗口，自定义组件统一从组件库或组件文件导入。主界面直接提供隐藏主窗口、开机自启动与开机静默启动，托盘右键只保留打开控制中心与退出；打开或重建主界面不写入启动登记，损坏的静默设置保持只读。

待办编辑窗口的原生标题栏和内容标题使用待办图标。待办与自定义清单增加“隐藏已完成 / 显示已完成”，选择随独立组件数据保存；隐藏不删除完成项，勾选后原位更新可见性，保留编辑窗口与未提交草稿。

## 2026-10-03 · 去除相邻组件顶部的系统阴影

实际并排对照复现了上方独立卡片的 DWM 投影在下方卡片顶部形成暗带；单独关闭非客户区绘制无效。组件改用持久的原生圆角区域，并关闭 DWM 圆角装饰，去掉相互覆盖的窗口投影，保留原生 Acrylic 和不激活行为。控制中心等普通窗口保持标准窗口装饰。

初始化、实际尺寸变化和动画收尾恢复完整圆角区域；静止轮询不重复应用。中英文各 283 项隐藏检查及独立进程回归通过，对照画面确认顶部暗带消失，详见 VALIDATION.md。

## 2026-10-03 · 组件浅色背景闪烁修复

移除布局轮询中对静止组件重复执行的原生窗口尺寸调整，以及动画帧中重复执行的位置与裁剪清理。仅在实际像素尺寸变化时调整大小；动画结束清除一次临时裁剪，即使最后一帧已到达目标像素位置。插件重启仍按实际窗口尺寸恢复当前 DPI 布局。

新增真实窗口消息回归，检查明暗主题下连续 120 次静止布局和帧更新、150% DPI 变化后的尺寸与位置，以及同像素位置的动画裁剪收尾。实际浅色背景的视觉验收单独记录。

## 2026-10-02 · 修复系统面板关闭后组件仍常驻

用户运行日志中，通知中心每次关闭后组件都从 shell_candidate 回到 manual_preview。原因是演示启动用了 --preview，而真实系统面板接管时未消耗预览状态；排列、启停、重置和编辑也会设置同一个常驻标志。WidgetFollow（widget-cards-follow-2）将显示会话与布局偏好分开：真实面板接管后结束预览，关闭时统一退场；布局操作不修改显示会话，编辑窗口只临时保留。快捷键在组件已显示时收起。正常启动不带 --preview。

## 2026-10-02 · 独立组件卡片

WidgetCards（widget-cards-1）替代原型的大面板：天气、待办、常用入口和系统状态各使用独立原生 Acrylic 窗口，宽 320 DIP、间距 8 DIP、圆角 8 DIP。按用户最新要求移除时钟、日历和专注计时。默认从系统面板旁的右下角向上、向左排列，允许使用其余工作区；不能覆盖已识别的系统面板和任务栏。关闭自动排列后可拖动标题，保存自由位置，支持启停卡片和重置。

全部卡片共用进出状态、时钟、曲线和帧调度器，重排也使用统一曲线。天气后台请求 Open-Meteo，支持城市修改和失败状态；待办支持增删、勾选及原子配置保存，文字输入使用独立编辑窗口。系统状态读取本机 CPU 和内存，常用入口打开资源管理器、设置和截图工具。尚未接入正式插件 SDK。

## 2026-10-02 · 排除消息通知横幅

用户截图和日志确认单条消息横幅与通知中心共用 Shell 的 CoreWindow 类，旧默认模式把未识别横幅当作可跟随对象。PanelFollow（panel-follow-6）保留广泛发现，但在进入候选清单、筛选和合并布局时要求已确认的通知中心/快速设置身份；不再凭通用窗口类、位置、大小或前台状态触发。收窄 UIA 通知容器的类匹配，展开/折叠按钮等叶节点不单独建立身份。

新增 follow_eligible / follow_exclusion 诊断字段；托盘默认项改为“跟随通知中心和快速设置”。未知窗口继续后台观察，保留手动预览，消息横幅不会替代已打开的面板。当前用户日志中的正常面板已有标题/结构身份，仍可通过快速原生路径跟随。

中英文各 90 项隐藏自测通过，新增横幅独立/并存/前台/大尺寸、真实面板关闭后横幅仍在及弱身份回归。只回放数据，没有发送实际消息或 UI 输入。输出在独立 PanelFollow 目录，保留正在运行的 FluentFollowFix；实际通知到达与正常联动待用户复测。

## 2026-10-02 · 整体动画、系统 Acrylic 与初始化崩溃修复

用户确认 BottomFollow 底部对齐正确、响应改善，要求动画和背景透明度接近原生通知中心；随后报告早期 FluentFollow 启动空指针错误。

FluentFollowFix（fluent-follow-5）为整个窗口连接系统 Acrylic Base，保留默认明暗配方和政策回退；默认跟随 Windows 系统主题，手动覆盖可从托盘恢复。自定义 SystemBackdrop 处理目标连接/断开，修复默认配置尚未准备好时的空指针读取。主题更新保留既有控件树及待办状态。

整窗背景与内容一起滑入/滑出，完整时长 250ms / 167ms，采用 Fluent 基准曲线。高精度时钟、DWM 配合的帧请求、UI 线程平移和最终占位裁剪；重复观察不重播，快速开关连续反向，关闭系统动画时直接开关。已观察的 Shell 激活链丢失可提前触发退场，仍需实测；没有公开 Shell 时间线，未宣称精确同步。

中英文各 78 项隐藏检查通过，包含空配置、六次主题切换、原生 HWND 动画完整循环及中途反向，退出码均为 0。新增测试专用诊断启动器捕获未处理异常，避免错误对话框打断用户；Release 产物保留 PDB 供诊断，目录分发包不含 PDB。旧版本保留，未操作用户进程、生产代码或工具链；新材质/动画的真实视觉验收待用户。

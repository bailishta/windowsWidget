# 随行组件 · 控制中心

Windows 11 / WinUI 3 主控制程序，统一管理天气、待办、常用入口、系统状态和用户自定义组件。没有时钟、日历或专注计时。

```powershell
./demo/NotificationCompanion/build.ps1 -Test -Package
./out/companion-demo/ControlCenter/WindowsWidget.exe
```

默认启动打开控制中心；关闭控制中心窗口后继续驻留托盘，单击托盘图标重新打开。再次运行主程序也会打开已有的控制中心。所有启停、设置、重启、顺序、主题和排列功能直接显示在主窗口。可以全部启用或全部停用。

主界面直接提供“隐藏托盘图标”“开机自启动”和“开机静默启动”，托盘右键保留“打开控制中心”和“退出”。点击主窗口右上角关闭按钮可隐藏控制中心，组件仍随系统面板显示。自启动默认关闭，静默选项默认开启；启用自启动后，在当前用户登录时只驻留托盘。取消静默可在登录时打开主窗口；普通双击始终打开控制中心。移动程序目录后，请取消再勾选自启动以更新路径。实际登录效果需要用户注销或重启测试。

正常情况下，组件随 Windows 通知中心或快速设置出现和收起。Ctrl+Alt+W 手动预览/收起；Ctrl+Alt+Q 退出。主窗口管理组件不会把它们变成永久显示。使用 --background 只驻留托盘，--preview 显式预览。旧 Demo 与新程序共用单实例锁，切换前退出旧版本。

所有组件都属于可选组件包，包括天气、待办、常用入口、系统状态和蓝牙电量。全新安装默认没有已安装组件，在“组件库 / 自定义组件”点击“安装组件”；旧版本升级会迁移原有选择、排列和数据。没有不可卸载的内置组件。

每个组件有自己的进程、窗口、数据目录与停止任务。控制中心负责系统面板检测、统一动画和位置：宽 320 DIP、间距 8 DIP、原生 Acrylic、进场 250ms / 退场 167ms / 重排 250ms。一个组件异常退出不影响其他组件，可在主窗口单独重启。四个标准组件各有独立编译的 EXE 和自包含 WinUI 运行时，通过公开的 process ABI 1 通道接入；DLL MOD 由独立的通用宿主进程承载。

主程序、托盘、控制中心列表和卡片标题使用统一的透明图标。天气、待办、系统状态、入口、蓝牙电量及四种用户组件类型各有独立标识；可通过组件清单的 icon 字段提供自己的 PNG。生成原图、ICO和完整提示词保存在 assets/icons。

自动排列默认靠系统通知一侧，从右下角向上、向左排列。关闭自动排列后拖动标题，自由位置会保存；上移/下移改变自动排列顺序。不能覆盖任务栏或已识别的系统面板。空间不足时相应组件暂时隐藏。

## 添加自己的组件

- **添加组件文件**：选择自己编写的 widget.json；验证后复制到组件目录，先显示为停用，可检查后启用。
- **打开组件目录**：每个组件一个目录，放入 widget.json 后点“重新扫描”。修改描述文件后重新扫描即可重新加载。
- 组件目录里的 **README.md** 是给用户与 AI Agent 的开发指南，配套提供 WidgetSdk.h 和 widget.schema.json，包含组件限制、界面设计、数据保存和可直接使用的开发提示词；源码在 sdk/components/README.md。
- examples 目录提供便签、文字和独立蓝牙电量 MOD。“我的清单”和“开发入口”两个重复示例已移除；已安装的包归档备份，独立数据保留。组件标题上的三点按钮已移除，管理功能统一放在主控制中心。

自定义组件支持 text / note / checklist / links，以及真正可编程的 native DLL MOD 和 process EXE 组件。native 通过现有 WidgetSdk.h 提供自己的 XAML 内容或原生子窗口、数据源与逻辑，不需要为新 MOD 修改或编译主程序。在组件库安装“蓝牙设备电量”可接入独立示例；最多显示四个已连接设备，缺少电量时显示未知。详见 docs/PLUGIN_DEV.md 和 widget.schema.json。

便签直接在卡片内编辑，停止输入 500 毫秒后自动保存，结束编辑时立即保存。待办与自定义清单可在卡片内添加、修改、勾选、删除，并使用“隐藏已完成 / 显示已完成”切换，完成项保留。删除条目不重建组件窗口，未提交草稿保留；编辑期间保留卡片位置，结束编辑后恢复跟随系统面板。天气默认使用 Open-Meteo，每 30 分钟自动更新；在控制中心的“天气与 API 设置”中可改为自定义 HTTPS JSON API，并设置认证请求头、JSON 字段路径、单位和更新间隔（5–1440 分钟）。认证值使用 Windows DPAPI 加密保存。API 地址支持 {city}、{lat}、{lon}，字段路径支持 now.temp 和 weather[0].description；只有温度必填。主界面和天气卡片不再提供更新按钮。系统状态以两张 64 DIP 高、10 DIP 网格的图显示最近一分钟 CPU / 内存使用率，每秒采样；常用入口保留三个位置，可在控制中心的“设置三个入口”中自定义名称、程序/文件/文件夹/网址和启动参数，目标留空会停用该位置。

## 数据与测试

数据根目录：%LOCALAPPDATA%\WindowsWidget\CompanionDemo。

- manager.json：组件启停、顺序、自由位置、排列、主题与隐藏托盘图标选择。
- startup.json：开机静默启动偏好；自启动登记在当前用户的 Windows 启动项。
- 程序目录 components/<名称>/：可选标准组件包；examples/：自定义示例组件。
- plugins/<id>/widget.json：所有已安装组件的定义，不分标准组件和自定义组件。
- removed-plugins/：卸载组件包的可恢复归档。
- plugin-data/<id>/：每个组件的独立数据和日志。
- companion.jsonl：主程序的检测和动画日志。

首次升级复制旧待办与天气配置到相应组件目录；之后组件独立保存，旧文件保留。点击“卸载组件”会停止它的独立进程，把整个安装包移出 plugins 并归档到 removed-plugins；plugin-data 保留。可从组件库或原组件包重新安装相同 id，继续使用原有数据。升级迁移标记确保卸载后的组件不会在下次启动自动恢复。全部卸载后仍可正常使用控制中心。

--data-dir 可指定独立目录。--self-test 验证原有窗口、动画、布局和描述文件；--runtime-test 在隐藏窗口中验证真实独立进程、导入、异常退出、重启、启停和顺序保存。--inspect 仅供界面检查，会允许卡片激活并出现在任务栏，不能用来验收“不激活”。

Windows 没有公开稳定的通知中心动画时间线；真实 Shell 同步、轻交互、多屏和全屏仍应实测。退出主程序会关闭全部子进程。子进程隔离不等于安全沙箱。
